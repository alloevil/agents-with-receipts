# incidents/ — 事故案例库

每条事故一个文件，编号递增。**没有证据链的条目不收。**

## 条目格式

```markdown
# NNN — 一句话标题（说清楚坏了什么）

- 日期：YYYY-MM
- 适用范围：任何 agent 工具 / 特定工具
- 证据：公开 commit / issue / 可复现步骤的链接

## 症状        ← 用户/维护者看到了什么
## 根因        ← 挖到底，不停在表层
## 修复        ← 具体做了什么，附 commit
## 沉淀        ← 事故变成了哪条规则 / 哪个测试 / 哪个 lint？
## 通用教训    ← 一句话，可迁移到其它项目
```

「沉淀」一节是本库和普通 post-mortem 的区别：**事故的价值在于它变成了机器可执行的防线**（AGENTS.md 条目、粘性规则、回归测试、lint 规则），而不是变成一篇没人再读的文章。
